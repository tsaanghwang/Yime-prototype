适合做默认底线

把“可复现的切分单位”与“是否已经是词典词条”分开判断；先确认边界、语法功能和材料类型，再决定准入、拒绝或暂缓。

  • 边界在相同上下文中应能由不同审查者稳定复现。
  • 材料可归为词、固定表达、专名或其他明确切分单位，而非偶然语料截片。
  • 频次只决定审查优先级；可由基本单位按语境能产组合的材料，无论频次多高都不静态收录。
  • 优先审查组合规则及其反例；规则覆盖的同族字串批量退出逐条人工队列。
  • 缺乏上下文或存在多种合理粒度时，优先暂缓并补证据。

依据： GB/T 13715-1992 · ISO 24614-1 · ISO 24614-2

适合语料标注与模型评测

采用一套声明过的粒度与词性/内部结构口径，重视跨样例一致性；不要把某一语料库的切分答案冒充唯一语言事实。

  • 先检查组合是否有稳定整体功能，再检查内部结构是否仍可自由替换或扩展。
  • 同类结构沿用同一粒度；遇到规范间均合理的多粒度分析时记录分歧。
  • 专名、缩略语、惯用搭配和能产构式分别分类，不用一个“成词/不成词”标签压平。
  • 能产构式以规则族为标注和评测单位，不把每个表面实例重复提升为静态词条。
  • 有争议项保留原始证据、审查者与改判历史，必要时交由第二审查者复核。

参考： Penn Chinese Treebank 切分准则 · 中文标注一致性方法 · 多粒度中文分词
